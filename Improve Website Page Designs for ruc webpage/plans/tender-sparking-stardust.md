# 러크 서버 페이지별 리디자인 계획

## Context
ruc-server.vercel.app (Next.js)의 6개 핵심 페이지를 "더 빨리 찾고, 더 풍부하게 느끼는" 방향으로 재설계한다. 현재 프로젝트는 빈 Vite + React 19 + Tailwind v4 스타터(src/App.tsx 비어 있음, react-router/motion 미설치)이므로 전부 신규 구축이다. 라이브 사이트의 CSS는 확인하지 못했다(텍스트 분석만 가능). 비주얼 방향 질문은 응답을 받지 못해, 기본값으로 "마인크래프트 감성 + 어두운 프리미엄 톤"을 가정한다. 다른 방향이면 알려주면 된다.

## 현황 분석 (사이트 구조)
- /landing, /en/landing: 헤더, 히어로(IP 복사, CTA 2개, 서버 상태 스트립), AT A GLANCE 3개, SERVERS 4카드(홈/약탈/국가전/평화), 클로징 CTA, 푸터
- /home: 허브. 4개 퀵링크 카드, 접속 패널(Java 1.21~1.21.11, IP), 상태 위젯
- /rules: 공통/디스코드/마인크래프트 탭, 0.1~0.6 규칙, 제재 1~10단계 표
- /wiki: 5개 카테고리, 하위 문서 17개 (/wiki/welcome 등)
- /charge: 멤버 등급 6종, RUC 충전 3종, 편의 2종, 입금 4단계 (오픈 전)
- /status: 총 접속자, 서버 4개, 공지 3건, 새로고침

## 공통 문제와 개선 원칙
1. IP 복사와 디스코드 CTA가 페이지마다 흩어져 있고 반복된다 → 모든 페이지 헤더에 고정 "IP 복사" 버튼과 상태 점(점등)을 둔다.
2. 검색이 있으나 눈에 띄지 않는다 → Cmd/Ctrl+K 커맨드 팔레트(페이지, 위키 17개 문서, 규칙 항목 통합 검색).
3. 정보가 긴 텍스트 나열이다 → 스캔하기 쉬운 카드, 스티키 목차, 아코디언, 필터.
4. 모션: /landing만 패럴렉스·3D. 나머지는 120~250ms 마이크로 인터랙션과 스태거 등장 정도로 절제(탐색 속도 우선).

## 구현 계획
- 의존성 추가: `react-router`(skill make:react-router 먼저 참조), `motion`, `lenis`(landing 부드러운 스크롤). 아이콘은 `lucide-react`.
- 디자인 토큰/폰트: 구현 직전에 `aesthetic-stance` 스킬 호출 + `create_make_theme` 1회. 폰트는 Google Fonts를 `src/index.css` 상단 `@import`로 연결(한글 지원 Pretendard 계열 또는 Noto Sans KR + 디스플레이 서체 1종). 토큰은 `src/index.css`의 Tailwind v4 `@theme`.
- 구조 (`src/main.tsx`는 유지, `src/App.tsx`에 라우터 연결):
  - `src/App.tsx`: 라우트 `/landing`, `/home`, `/rules`, `/wiki`, `/wiki/:slug`, `/charge`, `/status`, `/` → `/landing` 리다이렉트
  - `src/components/`: `SiteLayout`(헤더+푸터), `CommandPalette`, `CopyIp`, `ServerStatusDot`, `ServerCard`, `SectionLabel`
  - `src/pages/`: `Landing.tsx`, `Home.tsx`, `Rules.tsx`, `Wiki.tsx`, `WikiDoc.tsx`, `Charge.tsx`, `Status.tsx`
  - `src/data/`: `servers.ts`, `wiki.ts`(17문서 메타), `rules.ts`(규칙+제재표)  ← 사이트 실제 문구를 그대로 이식
- 서버 상태는 목업 데이터(현재 운영: 홈·약탈, 정지: 국가전·평화)를 사용. 실제 API 연결은 범위 밖.

## 페이지별 디자인
**/landing (패럴렉스·3D 전용)**
- 히어로: 레이어 4~5겹(하늘/먼 지형/중간 블록/전경/로고)이 스크롤·마우스 이동에 따라 서로 다른 속도로 이동, 아이소메트릭 블록 3D 틸트. 헤드라인은 글자 단위 리빌.
- AT A GLANCE: 스크롤 고정(sticky) 시퀀스. "하나의 지갑 → 도망은 없다 → 돈으로 못 사는 강함" 3장면이 교차 전환되며 3D 오브젝트(코인, 검, 체크 방패)가 회전.
- SERVERS: 4개 카드가 원근감 있는 가로 스택에서 스크롤로 펼쳐지고, 호버 시 마우스를 따라 3D 틸트와 글레어. 정지 중 서버는 흑백 처리.
- 상태 스트립: 히어로 하단 고정 칩(점등 애니메이션), IP 복사 시 토스트와 파티클.
- 클로징 CTA: 원근 줌 인 + 자석 버튼. `prefers-reduced-motion`이면 패럴렉스 비활성.
**/home**: 상단에 접속 패널(IP, 버전, 복사)을 먼저 배치, 이어서 4개 퀵링크를 "무엇을 하려고 왔나요?" 의도 기반 카드(접속하기/충전/규칙/위키)로 재구성. 상태 위젯은 가로 칩.
**/rules**: 좌측 스티키 목차 + 탭(공통/디스코드/마인크래프트) + 규칙 내 검색 필터. 제재 1~10단계는 단계가 오를수록 색이 진해지는 히트맵 표, 모바일에서는 카드 변환. 규칙별 앵커 링크 복사.
**/wiki**: 상단 큰 검색, 카테고리별 아이콘 카드 그리드, "처음이라면" 시작하기 경로를 최상단 강조. `/wiki/:slug`는 3단 레이아웃(목차/본문/이 문서 내 목차)과 이전·다음 문서 이동.
**/charge**: "오픈 예정" 상태 배너 + 디스코드 알림 CTA. 등급 6종 비교 카드(30일/골드 구분 배지), RUC 3종, 입금 4단계를 세로 타임라인(60분 타이머 강조)으로.
**/status**: 총 접속자 큰 숫자 카운터, 서버 4개 카드(온라인/오프라인 점등), 새로고침 버튼 + 60초 자동 갱신 카운트다운, 공지는 타임라인.

## 검증
- 개발 서버(이미 실행 중)에서 각 라우트를 브라우저로 열어 확인: 7개 라우트 렌더링, 헤더 IP 복사, Ctrl+K 팔레트, rules 탭/필터, wiki 상세 이동, landing 스크롤 패럴렉스(데스크톱/모바일 폭), reduced-motion.
- `pnpm build`로 타입/빌드 오류 확인 1회.

## 가정/미해결
- 비주얼 방향은 기본값 가정(위 Context). /wiki 하위 17개 문서 본문은 확인하지 못해 제목·요약 중심으로 구성하고 본문은 플레이스홀더.
- 영어 페이지(/en/landing)는 이번 범위에서 KO/EN 토글 UI만 두고 문구 번역은 포함하지 않음.
