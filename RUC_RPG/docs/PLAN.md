# 개발 계획 (지시서 §30 재정리)

지시서 §30 의 P0~P8 을 그대로 따르되, 각 단계를 **실행 가능한 작은 묶음**으로 나눴다.
앞 단계의 코드 위에 다음 단계가 올라가도록 순서를 정했다. ✅ = 완료.

## 디렉터리
```
web/app/rpg/page.tsx          로그인 게이트 (서버 컴포넌트)
web/app/api/rpg/ticket/       입장 티켓 (60초 JWT)
web/rpg/shared/               클라 · 서버 공용 — 상수 · 이동 · 공식 · 데이터 · 맵 · 문자열
web/rpg/client/               PixiJS 렌더러 + React HUD
RUC_RPG/server/               게임 서버 (Node 24 + ws + node:sqlite)
RUC_RPG/scripts/              맵 생성 등
RUC_RPG/docs/                 RECON · DECISIONS · PLAN
```

## P0 탐색·설계 ✅

## P1 기반 ✅
1. 공용: 상수(타일 16 · 틱 20Hz · 8방향), 8방향 계산, 이동 스텝(충돌 · 대각 · 달리기 · 스태미나), 조사 유틸, 티켓 서명/검증 + 단위 테스트
2. 맵: 광장 "솔라스" 96×96 생성 스크립트 → Tiled JSON (ground · water · decor_below · collision · decor_above · objects)
3. 웹: `/home` "RPG 시작" 카드, `/rpg` 게이트(비로그인 → 디스코드 로그인), `/api/rpg/ticket`
4. 서버: 티켓 검증 → 중복 접속 끊기 → 캐릭터 로드/생성 → 광장 채널(60명 초과 시 분리) → 20Hz 스냅샷 · ack · ping
5. 클라: 캐릭터 생성 화면, 픽셀 아트(타일 · 48×64 8방향 4프레임 걷기/달리기/대기 + 회전 보간), 예측 + 보정, 타 엔티티 100ms 보간
6. HUD: 미니맵 · 나침반 · 채널 · 우측 상단(FPS · 핑 · K/D/A · RUC · 종 · 톱니), 설정 팝업(Esc) — localStorage + 서버 저장
- DoD: 창 2개에서 서로 부드럽게 보임 · 비로그인 차단 · 60fps

## P2 전투 코어 ✅
1. 공용 공식 `shared/combat.ts`: 스탯 합산 (기본 + 레벨 + 속성 패시브 + 효과, 상한), 방어 상쇄, 속성 상성 · 속성 방어, 공속 → 시전 시간, 피해 공식 §13-1, 치유 · 정신 저항 · 회복 + 테스트
2. 상태효과 49종(버프 24 · 디버프 25) 정의(`data/effects.ts`) + 서버 엔진(`server/src/combat.ts`): 갱신 · 스택, hardCC 체감(50 → 25% → 면역) · 끝난 뒤 0.5초 면역, 정신계 저항, 강인함(에어본 제외), 보호막 먼저 생긴 것부터, 면역 정화, 얼음 둔화 3중첩 → 빙결, 젖음, 수면 해제, 도트 · 지속 회복
3. 스킬: 입력에 실어 보냄(D12) → 서버가 쿨 · 자원 · 상태 · 안전지대 검증 → 낙관적 재생, 거부(cf)되면 투사체 취소 · 자원 · 쿨 예측 롤백. 지연 보상 = 몹 위치 최대 150ms 되감기
4. 견습 스킬(D15): 맨손 평타(좌클릭 유지) · Q 마력 화살(속성 부가 효과) · W(C) 대시 베기 · E 응급 처치, Space 구르기(앞 0.2초 무적), 탈진 HP 감소, "표시 후 시전" 모드
5. 필드 "햇살 초원" 112×112 (`scripts/gen-field.ts`) + 포털(F) 왕복, 몹 4종(슬라임 · 토끼정령 · 고블린(대장 하급) · 덩굴 늑대) · AI(대기 · 순찰 · 추적 · 공격 · 리쉬) · 위협 · 바닥 경고 장판(고블린 강타 원형, 늑대 돌진 직선)
6. HUD: 마나 · 기력 구슬(물결), HP(지연 바 · 보호막) · 스태미나 바, 스킬 아이콘(시계 방향 스윕 · 남은 초 · 자원 부족 붉게 · 툴팁), 버프/디버프 줄(스윕 · 3초 깜빡임 · 스택 · 툴팁), 스탯창(접기 · 펼치기 · 상세, 바뀌면 0.5초 반짝), 네임 플레이트(디버프 · 등급 · 이름 · HP · 마나), 피해 숫자 · 치명타 흔들림, 속성 파티클, 16×16 아이콘
7. 사망 → 5초 뒤 광장 부활 · 경험치 3% 손실, 몹 처치 경험치 · 연속 레벨업(D18)
- 미룬 것: 적 지정 · 지면 · 채널링 · 차지 시전과 특수 효과 동작(P4 직업 스킬, D17), 사망 시 내구도 −5%(P3 아이템), 레벨업 빛기둥 · 스킬 레벨 상한(P4), 원소 반응(데이터만, 2단계 이후)
- DoD: 필드에서 슬라임 사냥, 스킬 · 디버프 · 속성 이펙트, HUD 실시간

## 실행 방법 (로컬)
```bash
cd RUC_RPG/server && npm install && npm run dev   # ws://localhost:2567 (개발 모드)
cd web && npm run dev                              # http://localhost:3000/rpg?dev=tester1
```
- `?dev=이름` 은 `next dev` 에서만 통하는 개발 로그인 (D6). 이름마다 다른 계정 → 창 2개에 이름을 다르게
- 봇: `cd RUC_RPG/server && node scripts/bots.ts 10` (광장에서 걷기) · `node scripts/bots.ts 39 ws://localhost:2567 field` (햇살 초원에서 마력 화살 사냥)
- 테스트: `cd RUC_RPG/server && npm test` (공용 공식 + 서버 E2E)
- 맵 다시 만들기: `node RUC_RPG/scripts/gen-plaza.ts` · `node RUC_RPG/scripts/gen-field.ts`
- 개발 모드 순간이동 (브라우저 콘솔): `__rpg.net.send({ t: "dev", map: "field", x: 736, y: 400 })` — 슬라임 언덕

## 운영 배포 (게임 서버는 Vercel 밖)
1. 게임 서버 기계(VPS 등)에 Node 24 → `RUC_RPG/server` 에서 `npm install` → `.env` (`.env.example` 참고) → `npm start`
2. 앞에 TLS(wss) — Cloudflare Tunnel 또는 nginx. 브라우저가 https 라 ws:// 는 막힘
3. Vercel 환경변수: `RPG_TICKET_SECRET`(서버와 같은 값) · `NEXT_PUBLIC_RPG_WS_URL=wss://…`
