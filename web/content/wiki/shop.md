모든 서버 공용. 구매품 · 판매 대금은 [우편함](/wiki/mailbox)으로.

| 여는 법 | |
|---|---|
| 메뉴 | Shift+F → 유저 상점 |
| 명령어 | `/유저상점` · `/상점` |

## 사기

물건 **더블클릭** → 확인창 **[구매]**.

## 팔기

| 명령어 | 기능 |
|---|---|
| `/판매등록 <가격>` | 손에 든 물건 등록 |
| `/판매등록 취소` | 내 판매 목록 (더블클릭 = 취소 · 우편 반환) |

| 규칙 | |
|---|---|
| 수수료 | 5% |
| 동시 등록 | 10개 |
| 기간 | 7일 (미판매 시 우편 반환) |
| 이용 불가 | 인증 전 · 평판 검정 |

> [!WARNING]
> 상점 밖 현금 · 타 게임 재화 거래 금지 ([규칙 0.5](/rules)). 상점 밖 거래는 보장되지 않음 — 사기 피해: 디스코드 `/신고` ([규칙 0.10](/rules)).
