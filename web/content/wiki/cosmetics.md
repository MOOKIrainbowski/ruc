## 여는 법

**Shift+F → 코스메틱** 또는 `/코스메틱`. 종류마다 **하나씩** 장착할 수 있고, 다시 누르면 해제됩니다.
고른 것은 어느 서버로 옮겨도 그대로 따라옵니다.

코스메틱은 [멤버 등급](/charge/member)으로 열립니다. 등급이 끝나면 보이지 않게 되고, 다시 등급을 사면 고른 것이 그대로 돌아옵니다.

> [!NOTE]
> 코스메틱은 **겉모습뿐**입니다. 펫은 무적이고 화살이 그대로 통과하며, 킬 이펙트의 번개 · 폭발도 피해가 없습니다.
> 투명 물약을 마신 동안에는 파티클 · 펫이 꺼집니다.

## 파티클 (16종)

몸 주위를 도는 입자입니다.

| 등급 | 열리는 것 |
|---|---|
| VIP | 하트 · 음표 · 초록 반짝이 |
| SVIP | 불꽃 · 눈송이 · 구름 · 마법 글자 · 보랏빛 마법 |
| MVP | 영혼불 · 별빛 · 벚꽃잎 · 전기 불꽃 |
| Prime | 야광 먹물 · 반딧불이 |
| Premium | 토템 빛 |
| Elite | 차원의 틈 |

## 펫 (12종)

오른쪽 뒤에서 따라다닙니다. MVP 부터 열립니다.

| 등급 | 열리는 것 |
|---|---|
| MVP | 아기 고양이 · 아기 여우 · 아기 토끼 · 병아리 |
| Prime | 앵무새 · 꿀벌 · 아홀로틀 · 개구리 |
| Premium | 아기 판다 · 아기 늑대 · 아기 아르마딜로 |
| Elite | 알레이 |

## 발광 (10색)

몸 테두리가 빛납니다. 이름표 색도 같은 색이 됩니다.

> [!WARNING]
> 발광은 **벽 너머에서도 보입니다.** 약탈 서버에서는 내 위치가 드러나니 주의하세요.

| 등급 | 열리는 것 |
|---|---|
| VIP | 흰색 |
| SVIP | 노란색 · 초록색 |
| MVP | 하늘색 · 빨간색 · 황금색 |
| Prime | 파란색 · 분홍색 |
| Premium | 보라색 |
| Elite | 무지개 (색이 계속 바뀜) |

## 킬 이펙트 (12종)

다른 플레이어를 쓰러뜨린 자리에서 터집니다.

| 등급 | 열리는 것 |
|---|---|
| VIP | 하트 폭발 · 승리의 음표 |
| SVIP | 눈보라 · 벚꽃 흩날림 |
| MVP | 불꽃놀이 · 영혼 이탈 · 차원 붕괴 |
| Prime | 붉은 파편 · 토템 섬광 |
| Premium | 폭발 · 번개 |
| Elite | 음파 폭발 |

윗 등급은 아래 등급의 코스메틱을 전부 쓸 수 있습니다.
