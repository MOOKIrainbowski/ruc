| 항목 | 내용 |
|---|---|
| 열기 | Shift+F → 코스메틱 · `/코스메틱` |
| 장착 | 종류별 1개 · 다시 클릭 = 해제 |
| 조건 | 멤버 등급 ([멤버 등급](/charge/member)) · 상위 등급은 하위 전부 포함 |
| 등급 만료 | 숨김 (재구매 시 복구) |

> [!NOTE]
> 겉모습 전용. 펫 무적 · 투사체 통과 · 킬 이펙트 피해 없음 · 투명 중 파티클 · 펫 숨김.

## 파티클 (16)

| 등급 | 항목 |
|---|---|
| VIP | 하트 · 음표 · 초록 반짝이 |
| SVIP | 불꽃 · 눈송이 · 구름 · 마법 글자 · 보랏빛 마법 |
| MVP | 영혼불 · 별빛 · 벚꽃잎 · 전기 불꽃 |
| Prime | 야광 먹물 · 반딧불이 |
| Premium | 토템 빛 |
| Elite | 차원의 틈 |

## 펫 (12)

| 등급 | 항목 |
|---|---|
| MVP | 아기 고양이 · 아기 여우 · 아기 토끼 · 병아리 |
| Prime | 앵무새 · 꿀벌 · 아홀로틀 · 개구리 |
| Premium | 아기 판다 · 아기 늑대 · 아기 아르마딜로 |
| Elite | 알레이 |

## 발광 (10)

| 등급 | 항목 |
|---|---|
| VIP | 흰색 |
| SVIP | 노랑 · 초록 |
| MVP | 하늘 · 빨강 · 황금 |
