| 질문 | 답 |
|---|---|
| 무료인가요? | 예. 판매는 꾸미기 · 편의뿐, 전투 능력치 판매 없음 |
| 베드락(모바일 · 콘솔)? | 불가 — 자바 전용 |
| 비정품? | 불가 — 정품만 |
| 디스코드 필수? | 인증에 필요. 인증 후에는 꺼 둬도 됨 |
| 서버 이동 시 아이템? | 인벤토리는 서버별. Gold · RUC · 레벨 · 평판 · 칭호 · 우편함은 공용 |
| 약탈에서 잃은 아이템 복구? | PvP · 약탈 · 처형은 복구 없음. 버그로 인한 손실은 `/ticket` |
| 모드 허용? | 성능 · 화면 표시 · 리소스팩 허용. 엑스레이 · 킬오라 · 오토클릭 금지 ([규칙 4](/rules#minecraft)) |
| 버그 발견? | `/ticket` 제보 시 보상, 악용 시 제재 |
| 구매품 미지급? | [충전 안내](/charge) 문의 방법 참고 |
