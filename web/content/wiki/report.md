## 신고

| 위치 | 방법 |
|---|---|
| 게임 | `/신고 <닉네임> <사유>` (3분에 1회) |
| 디스코드 | `/신고` → 양식 |

디스코드 양식 필수 칸:

| 칸 | 예시 |
|---|---|
| 가해자 닉네임 | `Steve` |
| 발생 시각 | `21:30` |
| 사유 | 약탈 스폰 반복 킬 |

증거(스크린샷 · 영상) 첨부 시 처리 빠름.

## 처리

1. 접수 — 변동 없음
2. 운영진 확인 → 확정 / 기각
3. 확정 시 평판 하락 + [제재 단계](/rules#sanctions) 적용

허위 신고 반복은 제재 ([규칙 0.6](/rules)).

## 제재 시

| 항목 | 내용 |
|---|---|
| 확인 | 접속 시 기간 · 사유 표시 |
| 소명 | 기간 종료 후 디스코드 `/ticket` |
| 영구 밴 (8단계 이상) | 소명 불가 |
