기능을 하나씩 해 보고 보상을 받습니다. 계정당 1회.

| 여는 법 | |
|---|---|
| 메뉴 | Shift+F → 가이드 |
| 명령어 | `/가이드` |

## 단계

| # | 단계 | 할 일 | 보상 (Gold) |
|---|---|---|---|
| 1 | 디스코드 인증 | 디스코드 `/인증` | 1,000 |
| 2 | Shift+F 메뉴 | 웅크린 채 F | 1,000 |
| 3 | 서버 이동 | 메뉴 → 약탈 | 1,000 |
| 4 | Gold 확인 | `/ruc` | 1,000 |
| 5 | 레벨 확인 | `/레벨` | 1,000 |
| 6 | 홈 지정 | 약탈에서 `/sethome` | 2,000 |
| 7 | 우편함 | Shift+F → 우편함 | 1,000 |
| 8 | 엔더상자 | Shift+F → 엔더상자 | 1,000 |
| 9 | 유저 상점 | Shift+F → 유저 상점 | 1,000 |
| 10 | 칭호 | `/칭호` | 1,000 |
| 11 | 신고 방법 | 가이드 화면에서 클릭 | 1,000 |
| 완주 | | | **30,000 + [ 가이드 ] 칭호** |

> [!NOTE]
> 순서대로만 인정됩니다. 현재 단계는 가이드 화면 · 접속 알림에서 확인.
