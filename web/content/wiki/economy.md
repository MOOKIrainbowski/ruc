## 화폐

| | Gold | RUC |
|---|---|---|
| 얻는 법 | 게임 플레이 | 디스코드 `/충전` (10원 = 1 RUC) · 현금 구매 적립 (5%) · 이벤트 |
| 쓰는 곳 | VIP · SVIP · 유저 상점 · 엔더 확장권 · [코스메틱](/wiki/cosmetics) | MVP 이상 · 충전 상품 |
| 잔고 | `/ruc` · `/골드` | `/등급` · 스코어보드 |

- 모든 서버 공용
- 2026-10-05 예전 화폐 Ruc → Gold 전환, 잔고 초기화
- 드래곤 알 보너스(+15%)는 직접 번 Gold 에만 적용

## 레벨

바닐라 경험치와 별개. 모든 서버 공용. 확인: `/레벨`.

전투로그 처형 시에도 레벨은 유지됩니다.

## 평판

| 색 | 의미 |
|---|---|
| 초록 | 최상위 신뢰 |
| 노랑 | 양호 |
| **빨강** | **신규 기본값** |
| 보라 | 주의 |
| 파랑 | 경고 이력 |
| 남색 | 제재 이력 |
| 검정 | 거래 제한 |

- 운영진이 신고를 **확정**해야 하락 (신고만으로는 변동 없음)
- 디스코드 역할에 15분마다 반영

### 올리기 — 주간 추천 `/추천 <닉네임>`

| 조건 | |
|---|---|
| 상대 | 지금 **같은 서버**에 있고, 이번 접속에서 **20분 이상** 함께 있었던 사람 |
| 횟수 | 주 1표 (월요일 0시 초기화) · 같은 사람은 4주에 1번 |
| 점수 | 추천한 사람의 평판으로 — 초록 +12 · 노랑 +8 · 빨강 +4 · 보라 이하는 추천 불가 |
| 서로 추천 | 4주 안에 A↔B 면 둘 다 절반 |
| 인증 | 두 사람 모두 디스코드 인증 |
