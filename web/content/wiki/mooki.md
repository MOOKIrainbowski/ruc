디스코드 채팅창에 `/` 입력 시 목록 표시.

## 명령어

| 명령어 | 기능 |
|---|---|
| `/인증 코드:<6자리>` | 계정 연결 ([인증](/wiki/verify)) |
| `/서버상태` | 열린 서버 · 인원 |
| `/ticket` | 문의 · 신고 · 건의 (전용 채널 생성) |
| `/신고` | 신고 양식 ([신고](/wiki/report)) |
| `/충전` | 상품 구매 · 현금 또는 RUC ([충전 안내](/charge)) |
| `/help` | 도움말 |

## 자동

| 기능 | 내용 |
|---|---|
| 역할 → 칭호 | 디스코드 역할 변경 시 게임 칭호 반영 |
| 평판 → 역할 | 15분마다 |
| 채팅 중계 | 게임 채팅 · 입퇴장 · 발전과제 → 서버별 채널 |

> [!NOTE]
> 중계는 게임 → 디스코드 한 방향.
