| 여는 법 | |
|---|---|
| 키 | 웅크린 채 **F** (바닐라 그대로, 모드 불필요) |
| 명령어 | `/메뉴` · `/서버` |

## 배치

```
[ 홈 ] [ 스폰 ] [ 약탈 ]          [ 내 정보 ] [ 인증 ] [ 언어 ]

[ 우편함 ] [ 엔더상자 ] [ 유저 상점 ] [ 코스메틱 ] [ 도움말 ] [ 가이드 ]

                         [ 닫기 ]
```

## 기능

| 칸 | 기능 |
|---|---|
| 서버 | 이동 · 접속 인원 (현재 홈 · 약탈) |
| 스폰 | 이 서버 스폰으로 |
| 내 정보 | 레벨 · Gold · 평판 · 킬/데스 |
| 인증 | 인증 상태 · 코드 — [디스코드 인증](/wiki/verify) |
| 언어 | 한국어 ↔ English |
| 우편함 | [우편함](/wiki/mailbox) |
| 엔더상자 | MVP 이상 — [엔더상자](/wiki/ender) |
| 유저 상점 | [유저 상점](/wiki/shop) |
| 코스메틱 | [코스메틱](/wiki/cosmetics) |
| 도움말 | 전투 · 이동 · 경제 요약 |
| 가이드 | [가이드](/wiki/guide) |

> [!NOTE]
> 인벤토리는 서버마다 따로. Gold · RUC · 레벨 · 평판 · 칭호 · 우편함은 공용.
