PvP · 약탈 · 건물 파괴 허용 ([규칙 6.1](/rules#minecraft)).

## 전투 태그

| 항목 | 내용 |
|---|---|
| 조건 | 때리거나 맞으면 **양쪽** (화살 · 물약 · TNT · 길들인 동물 포함) |
| 제한 | `/home` · `/spawn` · `/tpa` 불가 |
| 접속 종료 | 처형 (아래) |

## 도망자의 무덤 (전투로그)

> [!WARNING]
> 태그 중 접속 종료 → 짐은 **나간 자리의 무덤**으로, 다음 접속 때 **바닐라 경험치 삭제 후 사망**. 러크 레벨은 유지.

| 무덤 | |
|---|---|
| 처음 5분 | **싸우던 상대만** 열 수 있음 |
| 그 뒤 | 누구나 (도망친 본인은 끝까지 못 엶) |
| 30분 뒤 | 남은 짐 소멸 |
| 넣기 | 불가 — 꺼내기만 |
| 드래곤 알 | 무덤에 안 들어감 — 그 자리에 떨어짐 |

서버 재시작 · 서버 오류로 끊긴 경우는 처형되지 않습니다 ([규칙 6.2](/rules#rule-6.2)).

## 평판 현상금

평판 **보라 이하**는 약탈 서버에 있는 동안 **수배자**입니다.

| 항목 | 내용 |
|---|---|
| 현상금 풀 | 제재로 **몰수된 Gold** 가 쌓임 |
| 처치 보상 | 풀의 10% (최소 2,000 Gold, 풀이 적으면 전부) |
| 받는 조건 | 디스코드 인증 · 레벨 10 이상 |
| 수배 공지 | 2분마다 대략 위치(50칸 단위) |
| 면제 | 처치당한 수배자는 24시간 수배 면제 |
| 해제 | 평판이 빨강 이상으로 회복 |
| 확인 | `/현상금` — 풀 · 지금 수배자 |

> [!NOTE]
> 수배자를 처치하는 것은 게임 규칙입니다. 짜고 죽여 주며 현상금을 챙기는 것은 제재 ([규칙 6.3](/rules#rule-6.3)).

## 드래곤 알

1개. 스폰 근처 제단에서 등장, 소지자 사망 시 드롭.

**통치 시간** — 알을 가진 채 접속해 있는 시간이 시즌 기록으로 쌓입니다. 주인이 바뀌면 전 서버 · 디스코드 공지,
지금 주인과 순위는 [서버 상태](/status) 페이지에 실시간. 시즌 1위는 홈 광장 기념비에 이름이 남고 **[ 알의 군주 ]** 칭호를 받습니다.
확인: `/알순위`.

| 효과 | |
|---|---|
| 최대 체력 | +4 |
| 직접 번 Gold | +15% |
| 단점 | 발광 (위치 노출) |
