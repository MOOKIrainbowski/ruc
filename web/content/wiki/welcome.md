러크는 마인크래프트 서버 여러 개를 묶은 네트워크입니다. **Gold · 레벨은 모든 서버 공용**입니다.

| 항목 | 내용 |
|---|---|
| 주소 | `play.rucserver.kr` |
| 버전 | 자바 에디션 1.21 ~ 1.21.11 |
| 요금 | 무료 |

## 시작 순서

1. [디스코드 인증](/wiki/verify) — 인증 전에는 플레이 불가
2. [접속 방법](/wiki/join)
3. [네트워크 메뉴 (Shift+F)](/wiki/network-menu) — 서버 이동
4. [서버 규칙](/rules) — 약탈 서버 전투 규칙 필독
5. [가이드](/wiki/guide) — 단계별 Gold · 칭호 보상

## 서버

| 서버 | 상태 | 내용 |
|---|---|---|
| 홈 | 운영 | 광장 · 서버 이동 · 인증 |
| 약탈 | 운영 | PvP · 약탈 허용, 전투 중 접속 종료 = 처형 |
| 국가전 | 정지 | 길드 · 국가 · 영토 전쟁 |
| 평화 | 정지 | 살해 차단 |

## 문의

| 용도 | 방법 |
|---|---|
| 문의 · 건의 | 디스코드 `/ticket` |
| 규칙 위반 신고 | 디스코드 · 게임 `/신고` |
| 위키 검색 | 단축키 `/` |
