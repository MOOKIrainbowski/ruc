인증한 계정만 플레이할 수 있습니다. 1회만 하면 됩니다.

## 순서

1. [러크 디스코드](https://discord.gg/K3Z5CDn3GK) 참여
2. 서버 접속 → 채팅의 **6자리 코드** 확인 (다시 보기: `/인증`)
3. 디스코드 아무 채널에 입력:

```
/인증 코드:123456
```

성공 시 게임 제한 해제 + 디스코드 인증 역할 부여.

> [!WARNING]
> 본인 계정 1개만 연결. 대리 입력 · 다계정 연결은 제재 ([규칙 3.1](/rules#discord)).

## 실패할 때

| 원인 | 해결 |
|---|---|
| 코드 만료 | `/인증` 으로 새 코드 |
| 서버 점검 | [서버 상태](/status) 확인 |
| 계속 실패 | 디스코드 `/ticket` → 수동 승인 |
