러크 서버는 **디스코드 인증을 마친 계정만** 게임을 할 수 있습니다. 부계정으로 그리핑하고 사라지는 일을 막기 위한 절차입니다. 한 번만 하면 됩니다.

## 1. 디스코드 서버에 들어오기

[러크 디스코드](https://discord.gg/K3Z5CDn3GK)에 참여합니다. 공지 · 신고 · 서버 상태 · 길드 모집이 전부 여기서 돌아갑니다.

## 2. 인게임에서 코드 받기

서버에 접속하면 채팅창에 **6자리 코드**가 나옵니다. 놓쳤다면 `/인증` 을 입력하면 다시 보입니다.

## 3. 디스코드에서 입력하기

디스코드 아무 채널에서 다음을 입력합니다.

```
/인증 코드:123456
```

성공하면 게임 안에서 바로 제한이 풀리고, 디스코드에서 인증 역할이 붙습니다.

> [!WARNING]
> 인증은 **본인 마인크래프트 계정 하나**만 연결합니다. 다른 사람의 코드를 대신 입력하거나 여러 계정을 연결하면 제재 대상입니다 ([규칙 3.1](/rules#discord)).

## 인증이 되지 않을 때

- 코드는 시간이 지나면 바뀝니다. `/인증` 으로 새 코드를 받아 다시 입력하세요
- 서버 점검 중에는 인증이 실패할 수 있습니다. [서버 상태](/status)를 확인하세요
- 계속 안 되면 디스코드 `/ticket` → 문의로 알려 주세요. 운영진이 수동으로 승인할 수 있습니다
