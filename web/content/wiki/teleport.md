## 텔레포트 요청

| 명령어 | 기능 |
|---|---|
| `/tpa <닉네임>` | 상대에게 이동 요청 |
| `/tpahere <닉네임>` | 상대를 내 위치로 요청 |
| `/tpaccept` · `/수락` | 수락 |
| `/tpdeny` · `/거절` | 거절 |
| `/tpcancel` | 보낸 요청 취소 |

## 홈 · 스폰 (약탈)

| 명령어 | 기능 |
|---|---|
| `/sethome [이름]` · `/셋홈` | 홈 지정 |
| `/home [이름]` · `/홈` | 홈 이동 |
| `/delhome <이름>` · `/홈삭제` | 홈 삭제 |
| `/spawn` · `/스폰` | 스폰 이동 |

> [!WARNING]
> 시전 중 움직이면 취소. 전투 태그 중 `/home` · `/spawn` · `/tpa` 불가.
