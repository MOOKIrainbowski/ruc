## 텔레포트 요청

| 명령어 | 설명 |
|---|---|
| `/tpa <닉네임>` | 내가 상대에게 가겠다고 요청 |
| `/tpahere <닉네임>` | 상대를 내 위치로 부르겠다고 요청 |
| `/tpaccept` (`/수락`) | 받은 요청 수락 |
| `/tpdeny` (`/거절`) | 받은 요청 거절 |
| `/tpcancel` | 내가 보낸 요청 취소 |

## 홈 · 스폰 (약탈 서버)

| 명령어 | 설명 |
|---|---|
| `/sethome [이름]` (`/셋홈`) | 지금 위치를 홈으로 지정 |
| `/home [이름]` (`/홈`) | 홈으로 이동 |
| `/delhome <이름>` (`/홈삭제`) | 홈 삭제 |
| `/spawn` (`/스폰`) | 서버 스폰으로 이동 |

> [!WARNING]
> 이동에는 **시전 시간**이 있고, 그동안 움직이면 취소됩니다. 약탈 서버에서 **전투 태그**가 붙은 동안에는 `/home` · `/spawn` · `/tpa` 를 쓸 수 없습니다 — [약탈 서버](/wiki/raid) 참고.
