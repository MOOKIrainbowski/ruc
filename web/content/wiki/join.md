## 준비물

| 항목 | 조건 |
|---|---|
| 계정 | 자바 에디션 정품 (베드락 불가) |
| 버전 | 1.21 ~ 1.21.11 (권장 1.21.11) |
| 디스코드 | [인증](/wiki/verify)에 필요 |

## 서버 추가

1. 멀티플레이 → 서버 추가
2. 주소 `play.rucserver.kr` → 완료
3. 목록에서 더블클릭

> [!TIP]
> "연결할 수 없음" 이면 [서버 상태](/status) 확인.

> [!NOTE]
> 1.21.11 보다 낮은 버전은 새 블록 · 아이템 · 몹이 비슷한 모양으로 대체되어 보입니다. 판정은 같습니다.

## 첫 접속

홈 서버 인증 구역에 도착 → 채팅의 6자리 코드를 디스코드에 입력 ([디스코드 인증](/wiki/verify)).

## 문제 해결

| 증상 | 해결 |
|---|---|
| "1.21 이상으로 접속할 수 있습니다" | 1.21.11 로 실행 |
| 버전이 맞지 않음 (새 버전) | 1.21.11 로 실행 |
| "Failed to verify username" | 런처 재로그인 |
| 아무것도 못 함 | 인증 전 — `/인증` 으로 코드 확인 |
| 접속 직후 끊김 + 기간 안내 | 제재 중 — 기간 종료 후 `/ticket` 소명 |
