## 준비물

- **마인크래프트 자바 에디션** 정품 계정 (베드락 · 모바일은 아직 지원하지 않습니다)
- 게임 버전 **1.21.x**
- 디스코드 계정 — [인증](/wiki/verify)에 필요합니다

## 서버 추가하기

1. 마인크래프트를 실행하고 **멀티플레이**를 누릅니다
2. **서버 추가**를 누릅니다
3. 서버 주소에 `play.rucserver.kr` 을 입력합니다
4. **완료** → 목록에서 러크 서버를 더블클릭

> [!TIP]
> 서버 목록에서 러크 서버가 "연결할 수 없음" 으로 보이면 [서버 상태](/status) 페이지에서 지금 열려 있는지 먼저 확인하세요.

## 처음 접속하면

처음에는 **홈 서버의 인증 구역**에 도착합니다. 채팅창에 6자리 인증 코드가 보입니다. 이 코드를 디스코드에 입력하면 바로 풀립니다 — [디스코드 인증](/wiki/verify) 문서를 보세요.

## 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| "Outdated client" | 런처에서 1.21.x 버전을 골라 실행합니다 |
| "Failed to verify username" | 정품 로그인이 풀린 상태입니다. 런처에서 다시 로그인하세요 |
| 접속은 되는데 아무것도 못 함 | 디스코드 인증 전입니다. `/인증` 으로 코드를 다시 볼 수 있습니다 |
| 접속하자마자 끊김 + 기간 안내 | 제재 중입니다. 기간이 끝난 뒤 디스코드 `/ticket` 으로 소명할 수 있습니다 |
