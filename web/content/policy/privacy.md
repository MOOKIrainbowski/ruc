러크서버(이하 "서버")는 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고, 관련 고충을 신속하게 처리하기 위해 다음과 같이 개인정보처리방침을 정합니다.

---

### 제1조 (처리 목적)
서버는 다음 목적으로만 개인정보를 처리합니다. 목적이 바뀌면 미리 알리고 필요한 경우 동의를 받습니다.

1. **계정 연결과 본인 확인**: 마인크래프트 계정과 디스코드 계정의 1:1 인증, 역할 지급, 부계정·사칭 방지
2. **게임 서비스 제공**: 게임 데이터(레벨, 재화, 길드, 홈, 우편 등) 저장, 서버 간 이동, 랭킹·통계 표시
3. **유료 서비스 처리**: 주문 생성, 입금 확인, 상품 지급, 환불, 결제 분쟁 처리
4. **운영과 안전**: 규칙 위반 조사, 제재 집행과 기록, 신고·문의(티켓) 처리, 핵·부정 이용 탐지
5. **고지와 소통**: 공지, 지급·제재·만료 알림(디스코드 DM)

### 제2조 (처리하는 개인정보 항목)

| 구분 | 항목 | 수집 방법 |
|---|---|---|
| 마인크래프트 계정 | UUID, 닉네임, 첫 접속·마지막 접속 시각, 언어 설정 | 서버 접속 시 자동 |
| 디스코드 계정 | 사용자 ID, 사용자명, 서버 닉네임, 보유 역할 | 서버 가입·인증 시 자동 |
| 인증 | 연결된 디스코드 ID, 인증 시각, 인증 코드(발급 후 만료 시 삭제) | `/인증` |
| 게임 기록 | 레벨·경험치, 재화(Gold, RUC), 전투 기록, 평판, 길드·홈·우편·상점·칭호·코스메틱 보유 내역 | 게임 이용 중 자동 |
| 대화 | 게임 채팅 (디스코드 중계 채널로 전송됨), 티켓·신고 내용과 첨부 파일 | 이용 중 자동 / 이용자 제출 |
| 접속 기록 | IP 주소, 접속·종료 시각, 클라이언트 정보, 서버 로그 | 서버 접속 시 자동 |
| 웹사이트 | IP 주소, 브라우저 정보, 접속 시각 (호스팅 업체의 접속 로그) | 웹사이트 방문 시 자동 |
| 웹 로그인 | 디스코드 사용자 ID, 이름, 프로필 사진 주소, 관리자 여부 (브라우저 쿠키에만 저장) | 웹사이트에서 디스코드로 로그인 시 |
| 이용약관 동의 | 마인크래프트 UUID · 닉네임, 동의한 디스코드 사용자 ID, 동의 시각, 약관 판 | 웹에서 동의 시 |
| 결제 | 주문 코드, 상품, 금액, 주문·입금·지급 시각, 입금자명(주문 코드), 입금 알림 원문 | 주문·입금 시 |
| 환불 | 환불 계좌(은행, 계좌번호, 예금주) | 환불 신청 시 이용자 제출 |
| 보호자 동의 | 보호자 이름, 이용자와의 관계, 연락처(휴대전화 또는 이메일), 동의 항목, 결제 한도, 동의 일자 | 보호자 동의 신청 시 제출 |
| 미성년자 환불 | 가족관계 확인 서류, 법정대리인 신분증 사본 (주민등록번호 뒷자리 가림) | 해당 환불 신청 시 이용자 제출 |
| 제재 | 위반 조항, 단계, 기간, 증거 자료, 처리 운영진 | 제재 시 |

- 서버는 **실명, 주민등록번호, 전화번호, 마인크래프트 비밀번호, 카드 정보를 수집하지 않습니다.** 입금자명은 주문 코드를 쓰므로 실명도 받지 않습니다. 다만 은행이 입금 알림에 표시하는 정보는 예외일 수 있습니다.
- 마인크래프트 로그인은 Microsoft(Mojang) 인증 서버에서 처리하며, 서버는 인증 결과(UUID, 닉네임)만 받습니다.

### 제3조 (수집 동의와 근거)
1. 계정, 게임 기록, 접속 기록은 서비스 제공 계약 이행에 필요한 정보로 처리합니다 (「개인정보 보호법」 제15조 제1항 제4호).
2. 결제 기록은 「전자상거래법」 제6조에 따라 보관합니다.
3. 환불 계좌와 미성년자 서류는 해당 신청을 처리하기 위해 이용자가 직접 제출할 때 동의를 받아 처리합니다.

### 제4조 (공개되는 정보)
서비스 특성상 다음 정보는 다른 이용자에게 보입니다.
- 마인크래프트 닉네임, 칭호, 레벨, 평판 등급, 길드·국가 소속
- 게임 채팅 (게임 안과 디스코드 중계 채널)
- 랭킹, 전투 피드, 연대기 등 웹사이트와 디스코드에 게시되는 게임 기록
- 제재 공지: 닉네임, 위반 조항, 제재 단계와 기간. 증거 자료와 신고자 정보는 공개하지 않습니다.

### 제5조 (보유 기간과 파기)
1. 이용자가 탈퇴(계정 연결 해제와 데이터 삭제)를 요청하거나 처리 목적을 달성하면 지체 없이 파기합니다. 다만 다음 정보는 아래 기간 동안 보관합니다.

| 항목 | 보유 기간 | 근거 |
|---|---|---|
| 계약·청약철회, 대금 결제·재화 공급 기록 (주문, 입금, 지급, 환불) | 5년 | 「전자상거래법」 시행령 제6조 |
| 소비자 불만·분쟁 처리 기록 (환불 티켓) | 3년 | 「전자상거래법」 시행령 제6조 |
| 웹사이트·서버 접속 기록 (IP 등) | 3개월 | 「통신비밀보호법」 시행령 제41조 |
| 웹 로그인 쿠키 | 7일 (로그아웃하면 즉시 삭제) | — |
| 이용약관 동의 기록 | 탈퇴할 때까지 (동의 사실 증명) | — |
| 제재 기록 | 제재 종료 후 1년. 영구 제재는 해제될 때까지 | 제재 회피 방지 (운영정책) |
| 환불 계좌 | 환불 완료 후 30일 | 송금 오류 처리 |
| 보호자 동의서 | 탈퇴할 때까지. 결제 동의 기록은 마지막 결제 후 5년 | 「전자상거래법」 |
| 미성년자 확인 서류 | 확인 완료 즉시 파기 | — |
| 마지막 접속 후 1년 동안 이용하지 않은 계정 | 1년 후 분리 보관 또는 파기, 30일 전 디스코드 DM으로 알림 | — |

2. 전자 파일은 복구할 수 없는 방법으로 지우고, 출력물은 분쇄하거나 소각합니다.
3. 게임 세계(블록, 건축물, 표지판 등)에 이용자가 남긴 내용은 개인정보가 아닌 게임 데이터로 보며, 맵 초기화 시점까지 남을 수 있습니다. 표지판 등에 개인정보가 있으면 삭제를 요청할 수 있습니다.

### 제6조 (제3자 제공과 처리 위탁)
1. 서버는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 법령에 근거하거나 수사기관이 법령에 정한 절차로 요청하는 경우는 예외입니다.
2. 서비스 제공을 위해 다음 업체의 서비스를 이용하며, 그 과정에서 개인정보가 국외로 이전됩니다 (「개인정보 보호법」 제28조의8).

| 업체 | 이용 목적 | 이전되는 항목 | 국가 | 이전 시기·방법 | 보유 기간 |
|---|---|---|---|---|---|
| Discord Inc. | 커뮤니티, 인증, 티켓, 알림, 채팅 중계 | 디스코드 계정 정보, 메시지, 게임 채팅 | 미국 | 이용 시 네트워크 전송 | Discord 정책에 따름 |
| Vercel Inc. | 웹사이트 호스팅 | 웹사이트 접속 기록 | 미국 | 방문 시 네트워크 전송 | Vercel 정책에 따름 |
| Microsoft Corp. (Mojang) | 마인크래프트 계정 인증 | UUID, 닉네임 | 미국 | 접속 시 네트워크 전송 | Microsoft 정책에 따름 |
| [호스팅 업체] | 게임 서버 운영 | 서버에 저장되는 전체 정보 | [국가] | [ ] | 계약 종료 시까지 |

3. 국외 이전을 원하지 않는 이용자는 서비스 이용을 중단하고 제8조에 따라 삭제를 요청할 수 있습니다. 다만 위 업체들은 서비스 제공에 꼭 필요하므로, 이전을 거부하면 서비스를 이용할 수 없습니다.
4. 입금 확인에 쓰는 은행(토스뱅크)은 이용자가 직접 송금하는 금융기관이며, 서버가 개인정보를 맡기는 수탁자가 아닙니다.

### 제7조 (만 14세 미만 아동)
1. 만 14세 미만 아동의 개인정보는 법정대리인(보호자)의 동의를 받아 처리합니다. 동의 방법은 [보호자 동의 절차](/policy/guardian-consent)를 따릅니다.
2. 동의가 확인되기 전에는 `/인증`과 결제를 할 수 없으며, 접속에 꼭 필요한 정보(UUID, 닉네임, 접속 기록)만 처리합니다. 동의가 확인되지 않으면 그 정보도 파기합니다.
3. 동의를 받기 위해 법정대리인의 이름과 연락처를 아동에게서 받을 수 있습니다 (「개인정보 보호법」 제22조의2 제3항). 이 정보는 동의 확인 외의 목적으로 쓰지 않습니다.
4. 법정대리인은 아동의 개인정보 열람, 정정, 삭제, 처리정지와 동의 철회를 요구할 수 있습니다 (제8조).
5. 만 14세 이상 만 19세 미만 이용자가 유료 서비스를 구매하려면 같은 절차로 보호자의 결제 동의를 받아야 합니다.

### 제8조 (이용자의 권리와 행사 방법)
1. 이용자와 법정대리인은 언제든지 다음을 요구할 수 있습니다.
   - 개인정보 열람
   - 정정
   - 삭제
   - 처리정지
   - 동의 철회
2. 디스코드 [📥ㅣ문의](https://discord.com/channels/1406632846986051605/1413143952869167114) 채널의 `/ticket` 또는 [이메일]로 요청하면 **10일 이내**에 처리하고 결과를 알립니다.
3. 본인 확인을 위해 인증된 디스코드 계정으로 요청하거나, 게임 안에서 운영진이 알려 주는 확인 절차를 거쳐야 합니다.
4. 제5조에 따라 법령상 보관해야 하는 정보는 삭제 요청이 있어도 해당 기간 동안 분리 보관합니다.
5. 게임 데이터를 삭제하면 레벨, 재화, 아이템, 길드 소속, 구매 상품이 모두 사라지고 되살릴 수 없습니다.

### 제9조 (안전성 확보 조치)
1. **관리적 조치**: 개인정보 접근 권한은 Manager 이상 운영진으로 제한하고, 운영진에게 비밀유지 의무를 둡니다.
2. **기술적 조치**:
   - 게임 서버, DB, RCON은 외부에서 직접 접근할 수 없습니다.
   - 봇 토큰, 계좌번호 같은 비밀값은 공개 저장소에 올리지 않습니다.
   - 결제·제재 처리는 처리한 운영진과 함께 기록합니다.
   - DB는 정기적으로 백업합니다.
3. **물리적 조치**: 서버 장비와 백업 파일은 [보관 장소]에 두고 접근을 제한합니다.

### 제10조 (자동 수집 장치)
웹사이트는 광고나 행동 추적을 위한 쿠키를 쓰지 않습니다. 디스코드로 로그인하면 로그인 상태를 유지하는 쿠키(`ruc_session`, 7일)를 하나 둡니다. 호스팅 업체가 보안과 운영을 위해 접속 기록을 남길 수 있습니다. 앞으로 분석 도구를 도입하면 이 조항을 고치고 미리 알립니다.

### 제12조 (방침 변경)
이 방침을 바꾸면 시행 **7일 전**까지 디스코드 공지 채널과 웹사이트에 알립니다. 수집 항목이나 이용 목적, 제3자 제공처럼 이용자 권리에 중요한 변경은 **30일 전**까지 알립니다.
