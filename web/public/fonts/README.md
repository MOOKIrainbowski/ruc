# 폰트 라이선스

이 사이트는 **Galmuri11** 폰트를 사용합니다.

- 저작자: Lee Minseo (quiple) — quiple@quiple.dev
- 라이선스: SIL Open Font License 1.1 (OFL-1.1)
- 출처: https://github.com/quiple/galmuri
- 예약 글꼴 이름(Reserved Font Name): "Galmuri"

OFL 전문은 같은 폴더의 `OFL.md`(영문) / `OFL-ko.md`(한국어)에 있습니다.

OFL은 웹폰트로의 임베딩과 상업적 사용을 허용하며, 라이선스 전문을 함께
배포할 것을 요구합니다. 이 파일과 OFL 전문이 그 요건을 충족합니다.
폰트 파일 자체를 판매하거나 "Galmuri"라는 이름으로 수정본을 배포하는 것은 금지됩니다.
