## 0. 한 줄 요약

국가전 서버(25568)의 국가전 시스템(RucWar · RucGate 입장 제한)을 걷어내고, 새 플러그인 **RucRpg** 가 러크 RPG 의 시스템
(스탯 · 레벨 · 직업 30 · 스킬 159 · 상태효과 · 속성 12 · 아이템 희귀도 6 · 강화/마법부여/분해/재조합 · 상점/유저 상점 · 퀘스트 · NPC · 파티 · 던전 · 결투 · 영지 …)
을 Paper 1.21.11 위에 그대로 옮긴다. 화면(HUD · 아이콘 · 창)은 **리소스팩**(글꼴 HUD + 아이템 모델)으로 RPG 디자인과 같게 만든다.

## 1. 지시 → 해석 (사용자 원문 기준)

| 원문 | 해석 · 구현 방향 |
|---|---|
| 시스템은 모두 삭제 | 국가전 서버에서 **RucWar 플러그인 제거**(코드는 git 에 남김) · RucGate 의 국가전 입장 제한 해제 · 국가전 월드는 백업 후 새 RPG 월드로 교체. **RucCore(공용)는 건드리지 않음** |
| 아이템 · 스킬 아이콘 · 모든 디자인을 RPG 와 동일 | RPG 의 코드 그림(`web/rpg/client/art/*`)을 node 로 PNG 로 뽑아 리소스팩에 넣음(손으로 다시 그리지 않음 → 웹과 똑같음) |
| 핫바는 마크 칸 수(9) | RPG 핫바(5칸) 규칙을 9칸으로 |
| 스킬 · 적용효과는 핫바 위에 순서대로 | 핫바 바로 위 = 체력 · 스태미나 바, 그 위 = 스킬 줄, 그 위 = 버프/디버프 줄 |
| 마력 구슬 좌 · 기력 구슬 우 (픽셀) | 핫바 양옆에 도트 구슬 (채움 단계별 글리프) |
| 스탯 상세 칸 = 마력 구슬 왼쪽 | 마력 구슬 왼쪽에 스탯 표(글꼴 HUD), 서로 겹치지 않게 |
| 미니맵 같은 위치 · 화살표 대신 플레이어 머리 · 다른 플레이어도 머리 | RPG 와 같은 오른쪽 위. 내 위치 = 내 머리(8×8 스킨 얼굴), 다른 사람 = 그 사람 머리 → **방식은 질문 Q2** |
| 보호구와 검 = 기존 방어구만, 상급 이상 몹 → 상급 방어구 | 검 · 방어구는 **바닐라 모양**(가죽 → 사슬 → 철 → 금 → 다이아 → 네더라이트 = RPG 장비 단계). 몹 등급 `high`(상급) 이상이 상위 단계 방어구를 떨굼 |
| 마법부여 책 = 기존 + RPG 개념, 텍스처는 바닐라 책 | RPG 부가석(ench_atk · ap · def · hp · speed · crit · eldef · vamp)을 **바닐라 마법부여 책 모양**의 RPG 책으로. 바닐라 인챈트 책도 그대로 둠 |
| 팝업창 = 최대한 같은 시스템 | 인벤토리 · 스킬 · 퀘스트 · 상점 · 강화 … 를 상자 GUI + 글꼴 배경(양피지 창 그림)으로. 탭 · 버튼 위치 · 동작을 RPG 와 같게 |
| 기존 구현은 그대로 (스코어보드 RUC 등) | 스코어보드 · RUC · 길드 · 우편 · 칭호 · /tpa · Shift+F 메뉴 등 RucCore 기능은 손대지 않고 **가져다 씀** |
| 바닐라로 절대 불가 → 타협안 질문 | 12장 질문 Q1~Q4 |
| 언급 안 한 RPG 시스템은 전부 | 3장 표의 모든 줄 |

## 2. 구조

```
러크 RPG (TS)                         마크 RPG (Java · Paper 1.21.11)
web/rpg/shared/data/*.ts ──export──▶ RucRpg/src/main/resources/data/*.json   (콘텐츠 = 한 곳에서만 고침)
web/rpg/shared/combat.ts · progress.ts ─(손으로 옮김 + 같은 값 테스트)─▶ RucRpg engine/*
web/rpg/client/art/*.ts ──node 렌더──▶ minecraft/resourcepack/assets/ruc/textures/**   (아이콘 · 구슬 · 창 배경 · 글꼴)
web/rpg/shared/data/maps/*.json ──변환──▶ 국가전 서버 새 월드 (광장 · 초원 · 고원 · 던전 · 결투장)
```

- **새 Gradle 모듈 `RucRpg`** (`minecraft/plugins/RucRpg`, `compileOnly(project(":RucCore"))`). RucWar 는 settings 에 남겨 빌드만 되고 서버에는 안 올림.
- **콘텐츠 데이터는 TS 가 원본**: `RUC_RPG/scripts/export-mc.ts` 가 items · skills · jobs · mobs · effects · elements · economy · quests · dungeons · realm 을 JSON 으로 뽑음. 웹 RPG 를 고치면 다시 뽑기만 하면 마크도 같아짐.
- **공식은 Java 로 옮기고 같은 입력 → 같은 출력 테스트**: export 스크립트가 TS 공식으로 계산한 기준값(피해 · 스탯 · 필요 경험치 · 숙련도 · 강화 확률)을 `golden.json` 으로 같이 뽑고, JUnit 이 Java 결과와 비교.
- **단위 변환**: 16px = 1블록(캐릭터 40px ≈ 2.5타일 ≈ 플레이어 1.8블록), 사거리 300px = 18.75블록, 50ms 틱 = 1 마크 틱(20Hz 그대로).
- **저장**: RPG 데이터는 RucRpg 전용 H2(`servers/war/plugins/RucRpg/rpg.mv.db`, 이 서버만 씀 → 공용 DB 잠금 경쟁 없음). RUC 는 RucCore `EconomyService`(공용 화폐) 사용.
- **경제 멱등 · 원자성**(RPG `economy.ts atomic()` 규칙): 조작 하나 = DB 트랜잭션 하나, 아이템은 UUID(PDC) 하나가 주인 · 위치만 바뀜. 복사 버그 방지.
- **아이템 인스턴스**: 마크 아이템 PDC 에 `ruc:uid`(UUID) · `ruc:tpl` · `ruc:rarity` · `ruc:enh` · `ruc:ench` · `ruc:dur` … 를 넣고 표시(이름 색 · 로어)는 매번 템플릿에서 다시 그림. 아이콘은 `item_model` 컴포넌트(1.21.4+)로 리소스팩 모델 지정.

## 4. 화면(HUD) 설계

바닐라 하트 · 배고픔 · 방어 · 산소 · 경험치 숫자는 리소스팩에서 투명으로 지우고(바닐라 값은 서버 내부용), 아래를 글꼴 HUD 로 그린다.

```
                                            ┌────────────── 미니맵 (오른쪽 위, 머리 아이콘) ─┐
                                            └─────────────────────────────────────────┘
 (화면 가운데 위: 보스바 = 퀘스트 추적 · 보스 체력 · 파티원)

            [버프][버프][디버프]            ← 적용 효과 줄 (아이콘 + 남은 초)
            [패시브][Q][C][E][R]            ← 스킬 줄 (쿨타임 어둡게 + 숫자, 자원 부족 = 붉게)
            [■■■■ 체력 ■■■|■■ 스태미나 ■■]   ← 바 (눈금: 100마다 작은 · 1000마다 큰)
 [스탯 표]  (마나)  [1][2][3][4][5][6][7][8][9]  (기력)
            구슬                             구슬
            ──────── 경험치 바 (바닐라 경험치 바를 RPG 경험치로) ────────
```

- **방법**: 액션바 1줄에 글꼴 글리프를 나란히 놓음. 가로 위치 = `space` 글꼴(음수 · 양수 간격), 세로 위치 = 글리프 `ascent`(높이마다 다른 글꼴). 핫바도 화면 가운데 기준이라 GUI 배율이 바뀌어도 같이 움직여 안 겹침.
- **숫자 · 한글**: 픽셀 한글 글꼴(Galmuri, OFL 라이선스) `ttf` 공급자 + `shift` 로 줄마다 높이를 다르게.
- **구슬**: 마나(파랑) · 기력(주황) 각각 채움 0~32단계 글리프 + 숫자. 쓰지 않는 자원은 회색.

## 5-1. 미니맵 셰이더 (사용자 결정 Q2)

- 리소스팩 `assets/minecraft/shaders/core/rendertype_text.vsh`(1.21.11 형식)를 덮어씀: 글자 색이 약속한 표식 색(예: `#FE01xx`)이면 그 글리프를 **화면 오른쪽 위 기준**으로 옮기고, 미니맵 사각형 밖은 잘라 냄(fsh 에서 discard). 일반 글자는 손대지 않음.
- 지도 그림: 월드를 위에서 본 색(블록 지도 색 · 높이 음영)을 서버가 미리 구워 리소스팩 글리프(구역 조각)로. 플레이어 위치만큼 셰이더가 밀어서 스크롤.
- 머리: 플레이어 스킨 얼굴 8×8 은 리소스팩에 미리 넣을 수 없음 → **1.21.9+ `player` 객체 글리프**(채팅에 플레이어 머리를 그리는 바닐라 기능)를 쓰고, 안 되는 버전은 색 점으로. (Codex 리뷰에서 확인할 것)
- 셰이더를 못 쓰는 클라이언트(1.21~1.21.3 등 · Iris/OptiFine 셰이더 켬)는 미니맵이 엉뚱한 곳에 보이지 않도록 기본 색이 투명 → 안 보일 뿐 플레이에 지장 없음.

## 5-2. 몹 · NPC 3D 모델 (사용자 결정 Q3)

- **자체 모델 엔진**(RucRpg, 유료 ModelEngine 안 씀): 모델 = 뼈 트리(뼈마다 `ItemDisplay` 1개 + 아이템 모델 1개). 바닥에 보이지 않는 바닐라 몹(크기 = 판정 상자)이 이동 · AI 를 맡고, 뼈 디스플레이들이 그 몹에 탑승해 같이 움직임. 애니메이션 = 서버가 `Transformation` + `interpolation_duration` 으로 키프레임 보간(대기 · 걷기 · 공격 예비동작 · 공격 · 피격 · 사망 · 보스 패턴별).
- **모델 원본**: `RUC_RPG/scripts/mc-models/*.ts` — 몹마다 상자(큐브) 목록 · 뼈 · 텍스처를 코드로 정의(Blockbench 와 같은 Java 블록 모델 JSON 으로 출력). 텍스처는 RPG 그림(`art/mobs.ts` 색 · 무늬 · 눈 · 장식)을 기준으로 그려 **같은 몹이라는 게 한눈에 보이게**, 몹마다 실루엣이 다르게.
- 대상: 일반 몹 14(slime · rabbit · goblin · wolf · dusk_imp · stone_boar · frost_harpy · ember_golem · shade_knight · storm_drake · sprout_slime · shroom_shaman · moss_golem · shadow_vine) + 보스 5(tree_knight · twin_witch · purify_orb · fern · eldra) + 소환수 8 + NPC(광장 전원, 사람형 공통 뼈대 + 개별 옷 · 머리 · 소품).
- 피격 = 붉게 깜빡(디스플레이 `glow` 색 대신 피격용 텍스처 변형 모델로 2틱 교체), 등급 색 테두리 = 이름표 색.

## 6. 아이콘 · 그림 파이프라인 (Codex 담당 큰 줄기)

- `RUC_RPG/scripts/mc-art.ts`: 웹 코드 그림을 node 에서 그려 PNG 로(브라우저 캔버스 대신 `Px` 버퍼 → PNG 직접 인코딩, zlib). 대상:

## 7. 월드
