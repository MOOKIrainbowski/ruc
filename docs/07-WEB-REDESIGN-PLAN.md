## 원칙 (06 문서 §4 그대로)

- 보조 텍스트 대비 AA (`text-white/70` 이상) · 모든 버튼 `focus-visible` · 탭 ←/→
- 모션은 `prefers-reduced-motion` 이면 끔. 랜딩 외 페이지는 120~250ms 마이크로 인터랙션까지만 (찾는 속도 우선)
- 문구 · 데이터는 `content/` 와 `lib/` 의 것을 씀 — 디자인 작업에서 내용은 바꾸지 않음
