# 국가전 서버 — 2차 개발 (2026-10-10)

기준: 소유자 지시(2026-10-10) · `00-PLAN.md` Phase 4 (1차 구현 완료, 서버는 축소 운영으로 정지 중).

## 0. 먼저 한 것 — 드래곤 알 획득 방식 변경 (약탈)

| 전 | 후 |
|---|---|
| 오버월드 제단에 알 1개를 최초 1회 배치 | **엔더 드래곤을 처치하면 떨어지는 알만** 버프 알 (PDC 태그 `buff_egg`) |
| 바닥에 놓인 아무 드래곤 알이나 버프 | 태그 없는 알(바닐라 출구 포탈 알 · 크리에이티브)은 버프 없음. 바닐라 포탈 알은 아예 안 생기게 함 |
| 분실 시 `/raid egg` 가 제단에 다시 놓음 | 서버당 동시에 1개(`dragon_egg_live`). 공허로 떨어지면 공지 → **다음 드래곤 처치 때 다시** 떨어짐. `/raid egg` = 유통 중인 알이 없을 때만 스태프 손에 지급 |

- 땅에 떨어진 버프 알: 무적 · 소멸 안 함 · 몹이 못 주움 · 발광. 블록 설치 · 액자 · 호퍼 줍기 차단 (태그가 사라지거나 추적이 끊김)
- 전투로그 처형 · 도망자 무덤: 알은 지우지 않고 그 자리에 떨굼 (예전엔 처형 때 제단에 하나 더 생기는 경로가 있었음)
- 옛 제단의 알 블록은 첫 기동 때 치움 (배포본 config 의 `dragon-egg.altar` 좌표를 읽음). **제단 구조물(흑요석 · 기둥)은 그대로** — 지우려면 손으로
- 코드: `RucRaid` `DragonEggService` · `DragonEggListener` · `ExecutionService` · `GraveService` · `RaidCommands`

## 1. 지시 사항 → 구현

| 지시 | 구현 | 코드 |
|---|---|---|
| **러크 코어** — 설치하면 주변이 국가 영토. 신호기처럼 동작 → 발각 위험 | 이름 "러크 코어"(신호기). **오버월드 어디에나** 설치(`core.free-placement`, 예전 5거점은 false 로 되돌릴 수 있음). 하늘로 빛 기둥(END_ROD 입자, 최대 512블록에서 보임). `/전쟁` 에서 남의 코어 좌표는 `?` | `TerritoryService` · `TerritoryWatchService` · `WarCommands` |
| **강화대** (커스텀 텍스처 블록) | **화살 제작대를 리소스팩으로 다시 그림** (이름도 "강화대"). 우클릭 → 강화 화면. 웅크리고 우클릭 = 블록 놓기 | `UpgradeService` · `minecraft/resourcepack` |
| **강화 재료** (이름 미정, 픽셀아트) | **러크 강화석** (가칭) — item_model `ruc:upgrade_stone`, 브랜드 연두색 결정 | 〃 |
| 마법 붙은 아이템만, 최대 +10, 단계마다 성공률↓ · 하락/파괴↑ · 재료↑, +10 은 피드 채널 | 아래 표. +10 = 전 서버 공지 + 러크 연대기(피드 채널) | 〃 |
| 종전마다 **보급 상자** (배틀로얄) | 종전 때 6개를 스폰 반경 1,500 안에 떨구고 좌표 공지. 다음 보급 때 옛 상자 제거. 통(barrel) — 상자는 옆에 놓으면 합쳐져 규칙 우회 | `SupplyCrateService` |
| 오버월드 = 광물 · 자원 풍부 | 새로 생성되는 청크에 광맥 추가 (다이아 · 금 · 철 · 에메랄드 · 청금석 · 레드스톤 · 구리) | `RichOrePopulator` |
| 네더 · 엔드는 영토 없음 | 코어는 오버월드에만 → 네더 · 엔드에는 영토가 생기지 않음 | `TerritoryService.tryPlace` |
| 평시 남의 영토 진입 = **발광** + 주인 국가에 거리 · 방향. 보급 상자만 못 열고 채집 · 약탈 · 파괴는 됨 | 2초마다: 침입자 발광, 주인 국민 액션바 `⚠ 침입자 2명 | Steve 123m 북동 ↗` (화살표 = 내가 보는 방향 기준), 처음 들어올 때 채팅 경보. **평시 영토 블록 보호는 없앰** (중립 구역 · 코어 · 보급 상자만 보호) | `TerritoryWatchService` · `TerritoryService.canBuild` |

### 강화 표 (config `upgrade`, 전부 초안)

| 시도 | 성공 | 하락(-1) | 파괴 | 강화석 |
|---|---|---|---|---|
| +0→1 | 100 | 0 | 0 | 1 |
| +1→2 | 90 | 0 | 0 | 1 |
| +2→3 | 80 | 0 | 0 | 2 |
| +3→4 | 70 | 10 | 0 | 2 |
| +4→5 | 60 | 20 | 0 | 3 |
| +5→6 | 50 | 25 | 2 | 4 |
| +6→7 | 40 | 30 | 5 | 5 |
| +7→8 | 30 | 35 | 8 | 6 |
| +8→9 | 20 | 40 | 12 | 8 |
| +9→10 | 10 | 45 | 15 | 10 |

효과: 근접 무기 · 활 · 쇠뇌 · 삼지창 피해 +4%/단계 · 방어구는 받는 피해 -0.75%/단계(부위 합산, 최대 -40%) · 채굴 도구는 채굴 효율 +2/단계.
그 밖의 마법 아이템(낚싯대 · 겉날개 · 방패 · 마법 책)은 "강화 효과가 없는 아이템".
강화석 얻는 곳: 광석 채굴(다이아 5% · 에메랄드 6% · 금 1% · 고대 잔해 15%, 실크터치 제외) · 남의 코어 파괴 8개 · 보급 상자 2~5개.

## 2. 직접 제안해서 넣은 것

| 기능 | 왜 | 상태 |
|---|---|---|
| **코어 내구도 500 · 5×5×5 몸체** (2026-10-10 소유자 수정) — 무기로 때려 깎음(피해 = 무기 공격력 × 쿨다운 × 강화 배율), 캐기 · 폭발 불가. 0 이 되면 **귀속 없는 코어 아이템**으로 떨어짐 (주운 국가가 다시 박을 수 있음). 주인 국가 "공격받는 중" 경보 | 여럿이 동시에 공격 · 코어 탈취가 콘텐츠가 됨 | ✅ |
| **홈 어드밴티지** — 자기 영토 안 국민은 성급함 I | 평시 영토가 보호되지 않으니 "우리 땅" 의 이득이 필요 | ✅ |
| **전쟁 처치 점수** (`territory.points.kill` 10) | 코어 근처 전투가 시즌 랭킹(§3.5)으로 이어지게 | ✅ |
| **코어 파괴 전리품** (강화석 8개) | 공격 쪽 보상 — 강화 경제의 큰 공급원 | ✅ |
| 스태프 점검 명령 `/전쟁 강화석 [수]` · `/전쟁 보급` | 게임 안 확인용 | ✅ |

## 4. 배포 · 남은 것

- jar: 국가전 `RucWar.jar` · 약탈 `RucRaid.jar` 배포 (옛 jar `*.bak-20261010`, 서버 꺼진 상태). 국가전 config · messages 는 새 것으로 교체(옛 파일 `.bak-20261010`), 약탈 messages 는 옛 제단 문구 3줄만 삭제
- 리소스팩: `web/public/pack/ruc-war.zip` → **웹을 배포해야** `https://ruc-server.vercel.app/pack/ruc-war.zip` 이 열림. 국가전 `server.properties` 에 주소 · sha1 적어 둠(선택 수락, 강제 아님)
- 1.21.4 미만 클라이언트(ViaVersion)는 강화석이 프리즈머린 조각 모양으로 보임 — 기능은 같음
- **강화대 = 모든 화살 제작대.** 화살 제작자 주민의 작업대이기도 함 (주민은 그대로 씀)
- 코어 몸체 = 바리케이드 125칸 + 5배 신호기 BlockDisplay + 공격 판정 Interaction. 놓는 자리 주변 5×5×5 가 비어 있어야 함. 화살 · 삼지창 투척으로는 안 깎임 (근접만)
- ponytail 메모: 코어 내구도 · 보급 상자 목록은 메모리만 (재시작하면 내구도 가득 · 옛 상자는 다음 보급 때 안 치워짐)
