# 결정이 필요한 사항 (아키텍처에 영향)

`[DEFINE]` 항목은 전부 제가 설계안을 냈습니다(`01-DEFINE-DECISIONS.md`). 아래는 **제가 임의로 정하면 안 되는** 것들입니다 — 돈, 법적 책임, 또는 나중에 되돌리기 매우 비싼 결정이기 때문입니다.

## 🔴 Q1. 호스팅 — 가장 중요 (Phase 2 차단 중)

### 문제

§6.1은 "가장 좋은 **무료** 마인크래프트 호스팅"을 요구합니다. 그런데 이 프로젝트가 요구하는 것은:

- **서버 5개 동시 가동** (Velocity 프록시 + 홈 + 레이드 + 국가전 + 평화)
- **커스텀 플러그인 jar 업로드** (RucCore 등)
- **MySQL 데이터베이스** (4개 서버 공용 Ruc/XP/평판)
- **RCON 개방** (디스코드 봇 연동)
- **24시간 가동** (전쟁 시간대 스케줄러가 돌아야 함)

무료 호스팅의 구조적 한계는 브랜드와 무관하게 대체로 이렇습니다:

| 제약 | 이 프로젝트에 미치는 영향 |
|---|---|
| 아무도 없으면 서버가 잠듦 | **전쟁 시간대 스케줄러가 죽습니다.** 국가전 서버의 핵심 규칙이 동작 불가 |
| 무료 계정당 서버 1~2개 | 5개 인스턴스 불가 |
| 프록시(Velocity) 미지원 | 네트워크 구조 자체가 성립 안 함 |
| RAM 1~2GB | 4개 월드 + 커스텀 플러그인에 부족 |
| DB/RCON 미개방 | 공용 화폐·봇 연동 불가 |

**결론: 4개 서버 네트워크를 무료로 전부 돌리는 것은 현실적으로 불가능합니다.** 이건 호스팅을 잘 고르면 되는 문제가 아니라, 무료 티어의 구조적 한계입니다.

### 선택지

| 안 | 내용 | 비용 | 장점 | 단점 |
|---|---|---|---|---|
| **A. 단계적 무료 시작** | 무료 호스팅 1개에 **홈 서버만** 올려서 시작. 유저가 붙으면 유료로 이전 | 0원 | 지금 당장 시작 가능, 웹사이트에 실제 상태 표시 가능 | 잠듦 문제, 나중에 전체 이전 필요 |
| **B. 자택 호스팅 + 터널** | 소유자 PC에서 Paper 5개 구동 + playit.gg/ngrok 등으로 외부 공개 | 0원 (전기세) | **전 기능 구현 가능**, RAM/DB/RCON 전부 자유 | PC를 켜둬야 함, 가정용 회선 핑, 보안 설정 필요 |
| **C. 유료 VPS** | 4~8GB VPS 1대에 프록시+4서버+MySQL 전부 | 월 1.5~3만원 | 정석. 확장·백업·24시간 전부 해결 | 비용 발생 |
| **D. 하이브리드 (권장)** | **개발/테스트는 로컬(B), 공개 서버는 나중에 C로.** 지금은 Phase 0·1(웹사이트)부터 진행 | 0원 → 나중에 C | 돈 안 쓰고 실제 개발 진행, 유저 생긴 뒤 결제 | 공개 오픈 시점이 뒤로 밀림 |

### 제 권장안: **D (하이브리드)**

이유 — 지금 유저가 0명인 상태에서 서버 5개를 24시간 띄울 필요가 없습니다. 플러그인 개발은 로컬에서 하는 게 훨씬 빠르고(재시작 1초), 웹사이트는 호스팅과 무관하게 바로 만들 수 있습니다. **실제 공개가 필요해지는 시점(Phase 3~4 완료 무렵)에 VPS를 결제**하는 게 돈과 시간 양쪽에서 낫습니다.

### ❓ 확인 필요

> **`.env`에 `MC_HOST` / `MC_RCON_PORT` / `MC_RCON_PW`가 이미 채워져 있습니다.** 이미 어딘가에 마크 서버를 돌리고 계신가요? 어디인가요(무료 호스팅 / 자택 / VPS)? 그렇다면 그걸 기준으로 계획을 다시 잡겠습니다.

## 🔴 Q2. 마인크래프트 버전

§6.2는 "최적화가 완전히 지원되는 최신 버전, 아니면 플러그인 충돌 없는 최신 버전"을 요구합니다.

- **권장: Paper 1.21.x 계열 중 플러그인 생태계가 안정화된 버전으로 고정**
- 1.21 계열은 커스텀 아이템(코어), 데이터 컴포넌트, 스코어보드 API가 전부 충분합니다
- **최신 정식 버전은 피하는 게 맞습니다.** 출시 직후엔 WorldGuard·Citizens·ProtocolLib 같은 필수 플러그인이 대응을 못 해서, "플러그인 충돌 없는 최신"이라는 조건 자체를 못 지킵니다

### ❓ 확인 필요

> 버전은 **작업 시작 시점에 Paper 빌드 상태와 핵심 플러그인 대응 현황을 실제로 확인하고 확정**하겠습니다. 다만 방향만 정해주세요:
> - (a) **안정 우선** — 플러그인 전부 대응된 검증된 버전 (권장)
> - (b) **최신 우선** — 최신 버전으로 가고 플러그인은 직접 만들거나 기다림
>
> 또한 **자바 에디션 전용인가요, 베드락(모바일/콘솔) 동시 지원인가요?** 베드락 지원은 Geyser+Floodgate가 필요하고, UI·스코어보드·커스텀 아이템 설계가 전부 달라집니다. **나중에 붙이면 훨씬 비쌉니다.**

## 🟡 Q3. 커스텀 플러그인 개발 범위

이 명세의 핵심 기능들은 **기성 플러그인으로 대체 불가**합니다:

| 기능 | 기성품으로 가능? |
|---|---|
| 4서버 공용 Ruc | △ (일부 가능하나 커스텀이 나음) |
| 바닐라와 완전 분리된 자체 XP | ❌ 직접 개발 |
| 콤벳로그 시 아이템 무드랍 소멸 | ❌ 직접 개발 |
| 코어 설치 → 영토 탈취 전쟁 | ❌ 직접 개발 (가장 큼) |
| 간접 살해 전부 차단 | ❌ 직접 개발 |
| 드래곤 알 네트워크 전역 버프 | ❌ 직접 개발 |
| 7단계 평판 | ❌ 직접 개발 |
| 커스텀 스코어보드 | ❌ 직접 개발 |

→ **Java 플러그인 직접 개발이 프로젝트 작업량의 대부분**입니다. 제가 작성합니다(Gradle + Paper API). 다만 이건 웹사이트처럼 2~3일에 끝나는 규모가 아닙니다 — 특히 국가전(Phase 4)은 단독으로 가장 큰 덩어리입니다.

### ❓ 확인 필요

> Java 빌드 환경(JDK 21+)을 이 PC에 설치해도 될까요? 없으면 플러그인 컴파일·테스트가 불가능합니다.

## 🟡 Q4. "Ruc" 이름 충돌

MOOKI 봇에 **이미 RUC라는 화폐**가 있습니다 (`economy_data.json`에 실제 유저 잔고 데이터가 쌓여 있음 — 한 유저는 10억 보유). 그런데 §3.1의 Ruc는 마크 4개 서버 공용 화폐입니다.

| 안 | 내용 |
|---|---|
| **A. 통합 (권장)** | 디스코드 잔고와 인게임 Ruc를 **같은 화폐로 합침**. 계정 연동(`/인증`) 후 마이그레이션. 디스코드 활동으로 Ruc를 벌 수 있게 되어 커뮤니티 유입에도 유리 |
| **B. 분리** | 디스코드 미니게임 화폐 이름을 다른 것으로 변경. 기존 데이터 유지 |
| **C. 폐기** | 미니게임 경제를 §4.1대로 완전 제거, 기존 잔고 삭제 |

### ❓ 확인 필요

> 어느 쪽인가요? **기존 유저 잔고 데이터를 살릴지 버릴지**가 핵심입니다. C를 고르면 데이터가 사라지므로 되돌릴 수 없습니다 (백업은 남겨둡니다).

## 🟡 Q5. 결제 수단 (Phase 8)

§5는 소액결제와 구독을 요구합니다.

- **국내 유저 위주** → 토스페이먼츠 / 포트원(아임포트). 카드·계좌·간편결제 전부 지원
- **해외 포함** → Stripe. 단 한국 사업자 등록 필요
- **간이 방식** → Buy Me a Coffee, Ko-fi 등 후원 플랫폼 + 수동 역할 지급 (초기엔 충분)

### ⚠️ 법적 사항 (제가 대신 판단할 수 없는 부분)

한국에서 유료 아이템·구독을 판매하면 **통신판매업 신고**, **청약철회(환불) 규정**, 그리고 게임물 관련 규제가 적용될 수 있습니다. 미성년자 결제 환불 문제도 자주 발생합니다. **Phase 8 착수 전에 확인하시길 권합니다.**

### ❓ 확인 필요

> 수익화는 **일단 보류하고 Phase 0~7만 먼저 진행**해도 될까요? 초기엔 Ko-fi 링크만 붙여두고, 유저가 붙은 뒤 정식 결제를 붙이는 게 안전합니다.

## 🟢 Q6. 홈 서버 맵 라이선스

§2.3은 "온라인에서 자유롭게 사용 가능한 광장 맵을 찾아서 적용"을 요구합니다.

- 대부분의 공개 마크 맵은 **개인 사용만 허용**이고, **서버에 올리는 것(공개 배포)은 별도 허가가 필요**한 경우가 많습니다
- 수익화(§5)까지 하는 서버라면 상업적 이용 조건도 봐야 합니다

**제 방침:** 라이선스에 **서버 사용 허용이 명시된 맵만** 후보로 올리고, 라이선스 원문과 출처 URL을 `minecraft/home/MAP-LICENSE.md`에 보관하겠습니다. 조건에 크레딧 표기가 있으면 정보 보드와 웹사이트 푸터에 넣습니다.

### ❓ 확인 필요 (선택)

> 자체 제작을 원하시면(Builder 역할) 말씀해 주세요. 그 경우 임시로 간단한 광장을 생성해서 자리만 잡아두겠습니다.

## 통합 결정(Q4)에 따른 후속 작업

1. `economy_data.json` 백업 → `docs/backup/` 에 보관 (되돌릴 수 있게)
2. 주식·창업·상장·인수 등 **미니게임 로직은 제거**하되, **잔고(`money`)는 살려서** 인게임 Ruc 초기 잔고로 이관
3. `/인증` 계정 연동을 Phase 6의 **첫 번째** 작업으로 승격 (연동 없이는 잔고를 누구에게 줄지 알 수 없음)
4. 마이그레이션 시점까지 디스코드 잔고는 **동결**(지급/차감 중단) — 이중 지급 방지
5. ⚠️ 한 유저가 10억 Ruc를 보유 중입니다. 인게임 경제에 그대로 넣으면 즉시 파탄납니다. **환산 비율(예: 1/1000) 또는 상한선**을 적용해야 합니다 → Phase 6에서 재확인
