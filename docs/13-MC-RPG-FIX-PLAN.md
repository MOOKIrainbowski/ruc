# 13. 마크 러크 RPG — 2차 수정 계획 (2026-11-15 사용자 화면 확인 뒤)

> 사용자 지시 원문 요약: HUD · 미니맵이 깨진 네모 글자, NPC · 몹 텍스처가 보라/분홍 · 검정, 우편 수령 아이템이 인벤토리에 안 들어옴, 포션 · 영약은 바닐라 포션 모양 + 마시는 동작, 목걸이 · 반지 등 장착 칸을 E 인벤토리의 방패 칸 쪽에(종류마다 하나), 포털이 안 생김, 퀘스트 강조 = 그 곳 블록/텍스처 테두리 발광, 체력 · 스태미나는 바닐라 바(아이콘 줄), 마나 등도 바닐라처럼 아이콘 줄, 그 위에 스킬, 스탯 상세는 핫바 옆, 스킬 키 = Q · C · Z(기존 E/W) · R(궁극기) 로 시스템을 다시, 모든 스킬 · 이펙트를 확인해 다시 구현, 리스폰 뒤 못 움직임, M = 지도(웹 키 그대로), /지도 삭제 · 미니맵은 왼쪽 위만, 어려우면 시중 팩 · 모드 분석해 재창작, Codex 는 간단한 코딩 · 디자인만 · 나머지는 Claude, 새 계정 Codex 에게 자세히 안내.
> **사용자 결정 K1 (2026-11-15)**: 키는 **Fabric 클라이언트 모드**로 (웹 키 그대로 · 모드 필수, OptiFine 대신 Sodium/Iris).

## 0. 원인 (사용자 클라이언트 로그 `%APPDATA%/.minecraft/logs/latest.log` 로 확인)
| 증상 | 원인 |
|---|---|
| HUD · 미니맵 네모 글자 | 글꼴 134개가 전부 거부됨: bitmap 경로가 `ruc:hud/...`(→ `textures/hud/`) 인데 파일은 `textures/font/hud/`, `chars` 줄이 배열 · 빈 칸, `ascent > height`, `Galmuri11.ttf` 대문자 경로 |
| NPC · 몹 보라/검정 | 모델 텍스처 `ruc:entity/mob/...` 가 블록 · 아이템 아틀라스에 없음(1.21 아틀라스는 정해진 폴더만) → "Missing textures in model" 1,300여 건 |
| 기타 | `heartPlus` 등 대문자 경로 무시, 클라이언트 = OptiFine 1.21.11(코어 셰이더 위험) |
→ **검증 없는 팩을 운영에 올린 것이 근본 원인.** 이제 팩마다 `scripts/pack-validate.py`(경로 · 아틀라스 · 글꼴 규칙 · JSON)를 통과해야 묶음. 가능하면 실제 클라이언트 로그로 확인.

## 1. 단계 (Claude 주도, Codex = 간단한 코딩 · 그림만)
| 단계 | 내용 | 완료 기준 |
|---|---|---|
| F0 | **팩 고치기**: 모델 텍스처 아틀라스 등록(`assets/minecraft/atlases/blocks.json`/`items.json` 에 `entity/mob` 폴더), 대문자 경로 정리, 깨진 글꼴 정리(HUD 는 모드가 그림 → 서버 글리프 HUD 글꼴은 뺌), `pack-validate.py` | 검사기 0 오류, 사용자 클라이언트 로그에 Missing/Failed 0 |
| F1 | **Fabric 모드 뼈대** `minecraft/client/ruc-rpg-client`(1.21.11 · Fabric API · Java 21): 서버 ↔ 모드 채널 `ruc:rpg`(악수 · 키 · HUD 상태 · 지도 · 강조), 키 = 웹 기본키(Q · C · Z · R 스킬, M 지도, V 장비, K 스킬창, J 퀘스트, P 파티, B 창고, O 소셜/영지, G 핑, F8 GM, Space 구르기). 모드가 없으면 RPG 서버 입장 때 설치 안내 후 내보냄. 배포 = 웹에 jar + 설치법 | 모드로 접속 → 키마다 서버 동작 확인(봇 대신 모드 자체 시험 + 사용자 확인) |
| F2 | **HUD (모드가 그림, 픽셀 아트)**: 체력 = 바닐라 하트(서버가 체력 비율로), 스태미나 = 바닐라 배고픔 줄, 마나/기력 = 바닐라 같은 아이콘 줄(배고픔 위), 그 위 스킬 칸 4(Q · C · Z · R · 쿨 · 자원 부족), 효과 줄, 스탯 상세 = 핫바 왼쪽, 미니맵 = **왼쪽 위**(맵 그림 · 내 방향 · 파티/다른 사람 머리 = 실제 스킨), M = 전체 지도 화면. 서버 글리프 HUD · 보스바 미니맵 · /지도 는 삭제 | 사용자 화면 확인 |
| F3 | **버그**: 우편 수령 아이템 안 들어옴, 리스폰 뒤 못 움직임, 포털(보이는 문 + 실제 이동) | 봇 · 시험 서버로 재현 → 고침 → 재시험 |
| F4 | **포션 · 영약** = 바닐라 포션 아이템 모양(색만 다르게) + `consumable` 마시기 동작/소리 | 마시는 동작 확인 |
| F5 | **장신구 칸**: E 인벤토리의 2×2 제작 칸 4 + 방패(왼손) 칸 1 = 장갑 · 망토 · 반지 · 목걸이 · 귀걸이(종류마다 하나, 반지 1개로). 제작 결과 막기, 닫을 때 돌려주기 막기, 원본 = EquipStore | 끼우고 빼고 · 다시 접속 · 죽음 뒤 유지 |
| F6 | **퀘스트 강조 = 발광 테두리**: 서버가 목표(블록 · NPC · 몹 id)를 보내면 모드가 그 플레이어에게만 발광 윤곽 | 화면 확인 |
| F7 | **스킬 전수 점검 · 재구현**: 164 스킬을 웹 정의와 하나씩 대조(판정 · 피해 · 효과 · 이펙트), 이펙트는 웹 그림 기반 스프라이트(Codex 그림) + 파티클 | 스킬별 표(정상/고침) 문서화 |

순서: F0(바로 눈에 보이는 고장) → F3(버그) → F1 → F2 → F5 · F4 → F6 → F7. 단계마다 커밋 · 운영 폴더 반영(서버는 사용자가 켬).

## 2. 결정 기록
- R10 (K1) 키 = Fabric 모드. 모드가 HUD · 미니맵까지 그림 → 보스바/셰이더 미니맵 · 글리프 HUD 폐기(그 팩 파일 · 계약은 정리).
- R11 장신구 칸 = 제작 2×2 + 왼손 칸(바닐라 화면 안에 새 칸을 만들 수 없음 — 빈 자리는 그 둘뿐). 반지는 1개(사용자: 종류마다 하나).
- R12 미니맵 위치 = 왼쪽 위(사용자 최신 지시, 앞선 "오른쪽 위"를 바꿈).
- R13 Codex 역할 축소: 그림(HUD 아이콘 · 스킬 이펙트 스프라이트 · 슬롯 틀) · 간단한 생성기만. 모드 · 서버 · 팩 구조 · 검증 · 커밋 = Claude.
